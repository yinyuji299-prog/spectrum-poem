音高实验室

标题叫《频谱之诗》——"频谱"是算法，"诗"是声音。这一页把两者接到一起： 你弹一个音，它既是某段振动曲线，也是频谱上的一根（或几根）柱子。 声音只在本机合成与处理，不会上传。

灵感从哪来
我最近研究了一个叫落谱（luopu.net）的工具：上传一首歌，它能自动识别出旋律、和弦、歌词， 并转成简谱 / 五线谱 / 吉他谱，再让你在谱面上手动精修。说到底，它做的是一件和本站同源的事—— 把声音变成可读的"音"。本页受它启发，但完全由我离线实现： 用 Web Audio 合成乐音、用实时 FFT 画出频谱，并做了一个"听音辨频"小游戏； 最后一节还能上传你自己的音频，用本页的 FFT 实现对它做一次真实的频谱分析。 落谱是这件事的工业级产品，本页是它的教学切片。

补充 · 十二平均律

"音高"其实是算出来的频率

现代音乐采用十二平均律：把一个八度均分成 12 个半音，相邻半音的频率比恒为 2^(1/12) ≈ 1.0595。以 A4 = 440 Hz 为基准，任意音的频率由下面这条公式给出—— 它和傅里叶变换无关，却解释了"为什么每个音都有一个确定的频率"，而频谱要找的正是这些频率。

相邻两行频率之比都约等于 1.0595；八度（如 C4→C5）恰好是 2 倍—— 这正是"高八度 = 频率翻倍"的数学来源，也是频谱图上一个音及其谐波间距的由来。

真实数据 · 你的声音

上传一段音频，看它真正的频谱

前面所有实验里，声音要么是我合成的、要么来自你的麦克风。这一节再进一步： 选一个浏览器支持的本地音频文件（如 mp3、wav、m4a 或 ogg）， 我会用本页自己的 FFT 实现对它做一次真实的频谱分析；很短的音频也会自动补零后计算。

为什么要做这一节
落谱那类工具，第一步就是"把音频拆成音高"——而这一步在数学上， 正是把一段真实采样做一次傅里叶变换。 前面三节把它拆成了可玩的小步骤，这一节把它合回去： 给你自己的真实文件，输出真实的频谱。
尚未选择文件。支持 mp3 / wav / m4a / ogg 等浏览器能解码的格式。
分析完成后，这里会显示主频及其对应的音名。

原理：先用浏览器解码出采样序列，取其中能量最大的 2048 个采样点；短音频不足时自动补零， 再加 Hann 窗抑制频谱泄漏，交给第 3 章那套基-2 时域抽取 FFT 逐级计算。 全程在你的浏览器里完成，文件不会上传到任何服务器。

延伸阅读 · 现实里的同类工具

落谱：把这件事做成产品

落谱（luopu.net）

落谱是一个 AI 扒谱工具：上传一段音频（如 MP3），它先用音频识别给出旋律、和弦与歌词的初稿， 再让你在谱面上手动精修音高、做原曲 / 伴奏 / 人声三档混音、对齐多语言歌词， 最后导出简谱、五线谱、吉他谱、钢琴谱，以及图片、PDF、动态谱视频、伴奏分轨、MIDI、Guitar Pro、MusicXML。

它和本页做的是同一件事的工业级版本——把声音变成可读的"音"。 区别只在于规模：落谱面对的是一整首歌里交叠的人声、乐器与节奏； 本页则用一根干净的琴键，把"音频 → 频率 → 音名"这一最小单元演示给你看。

本页不依赖落谱，也不调用任何外部服务：乐音由 Web Audio 实时合成，频谱由浏览器原生 FFT 计算， 全部离线可跑。把它当作落谱的"原理预习"即可。
