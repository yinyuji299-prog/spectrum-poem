> 本说明按「第十四届全国大学生数字媒体科技作品及创意竞赛」评审维度撰写，便于评委逐项核验。

| 项目 | 内容 |

| 作品名称 | 频谱之诗 —— FFT 算法的视觉化与交互式科普 |

## 一、选题价值与导向（对应「选题价值与导向」10 分）

频谱分析是现代工程的通用语言：手机降噪、电机状态监测、医学影像重建、无线通信的底层，都是同一套快速傅里叶变换（FFT）。但它在教学上长期存在一个痛点——**"看不见"**：

- 教材给出静态流程图与公式推导，读者记住结论，看不清过程；
- 现成演示多为预制播放，观众无法改输入、无法验证自己是否真懂；
- 学生能背出"复杂度 N·log₂N"，却说不清"蝶形运算到底在算什么"。

本作品面向**非电子 / 通信专业的普通大学生**，回答一个朴素的真问题：**"一段混在一起的声音里，到底藏着哪几个音？"** 把算法拆成能拖、能点、能听见的小步子，让理解在动手里自然发生。导向清晰：用同龄人能懂的方式，把硬核算法讲成人话。

## 二、创新性与原创贡献（对应「创新性与原创贡献」25 分）

本作品的创新不在另写一套理论，而在**教学呈现与工程实现方式**上做了四项原创设计（已同步呈现在首页"原创贡献"板块）：

1. **把算法拆成能拖、能点、能听见的小步子。** 同一份 FFT，被拆成可拖动滑块、可点击推进按钮、可听见的频率，每一步先动起来再讲道理。这是面向同龄学习者的教学设计创新。
2. **核心交互图形由代码实时算出来。** 全站 24 块 Canvas 中的波形与频谱条均由本站傅里叶变换逐点绘制；首页 75 秒剧场与头顶"会呼吸的频谱"均为浏览器实时计算。
3. **同一道题，笨办法和聪明算法并排跑。** 用对数坐标把"点数翻倍、计算量翻四倍"的 DFT 与"点越多省得越多"的 FFT 拉到同一画面，拖动滑块即见差距拉开，复杂度从符号变成可看见的事。
4. **零依赖、可核验的工程底座。** 无 CDN、无外部字体、双击即开；内置 FFT 与"按定义逐点计算"的 DFT 交叉比对，16 点输入最大误差 3.35×10⁻¹⁴，达双精度机器精度，演示结果可复算、可核验。

教学内容的原创组织：公式统一采用"**先大白话 → 再思路 → 才上公式 → 最后逐符号翻译**"的四步法，并为每个首次出现的术语（信号、采样、频率、复数、相位、谐波）在出现前补上生活化定义。

**竞品空缺实证（2026-10-12 调研）**：对中文视频平台检索「FFT 蝶形运算 可视化」「傅里叶变换 直观理解 科普」两个关键词共 20 条高播放结果，结果全部集中于两类：① 考研/课程复习（如"数字信号处理""期末考试"）；② MATLAB/Simulink 等工程工具操作。播放量最高的科普类内容（如"坐标分解""圆上圆"）为**纯视频讲解**，观众无法改变输入、无法验证理解。**面向普通大学生的"可交互、可亲手验证"的 FFT 科普内容，在本次检索范围内属空缺**——本作品正是填这一空缺，而非重复已有内容。

## 三、技术实现与规范（对应「技术实现与规范」25 分）

| 层面 | 方案 | 说明 |
|---|---|---|
| 结构 | HTML5 | 8 个静态页面（首页 + 5 章 + 音高实验室 + 整合总览），无框架 |
| 样式 | CSS3 手写 | CSS 变量统一设计令牌，响应式布局，移动端可用 |
| 逻辑 | 原生 JavaScript | ES5 语法、无构建步骤、无依赖管理，可双击直接运行 |
| 结构图 | SVG | 矢量可缩放，节点由脚本动态生成 |
| 波形/频谱 | Canvas 2D | 按设备像素比（DPR）适配清晰不模糊；仅尺寸变化时重设画布，避免动画循环反复重分配 |
| 音频 | Web Audio API | AnalyserNode 实时频谱；decodeAudioData 解码上传音频；file:// 下优雅降级 |
| 算法 | 自实现 | DFT 按定义实现；FFT 基-2 时域抽取，保留各级快照 |

**关键实现点：**
1. **FFT 保留中间快照**：每级运算后复制数组状态，支持"逐级回放"——教学场景的必要设计。
2. **零外部依赖**：无 CDN、无外部字体、无接口请求，保证在评审离线环境完整运行。
3. **半径自适应**：蝶形节点圆圈半径随标签长度动态调整，连线端点按真实半径计算，避免溢出或穿透。
4. **真实数据而非预制动画**：麦克风频谱与上传音频分析均取浏览器原生采样数据，再交由本站 FFT 处理，观众看到的每根柱子都来自自己的声音或文件。
5. **动画性能自律**：实时画布仅在像素尺寸变化时重设 `canvas.width/height`，缓存容器宽度、只在 resize 时重新测量，避免 requestAnimationFrame 中反复重排。

## 四、完成度与可验证性（对应「完成度与可验证性」20 分）

- **规模完整**：5 章 + 1 个延伸实验（音高实验室），共 **14 个可动手互动任务**、24 块实时画布。
- **进度可核验**：任务完成状态写入 `localStorage`，首页进度条与徽章实时反映探索进度，评委可现场逐项验证。
- **算法正确性验证**：内置 FFT 与朴素 DFT 逐点比对，误差量级 1e-15（双精度极限）：

| 测试信号 | 最大误差 | 频谱结果（|X[k]|） |
|---|---|---|
| cos(1 周期) | 3.9e-15 | 0, 4, 0, 0, 0, 0, 0, 4 |
| cos(2 周期) | 2.4e-15 | 0, 0, 4, 0, 0, 0, 4, 0 |
| 方波 | 3.8e-15 | 0, 5.23, 0, 2.16, 0, 2.16, 0, 5.23 |
| 冲激 | 0 | 全 1（频谱平坦） |
| 直流 | 3.6e-15 | 8, 0, 0, 0, 0, 0, 0, 0 |

- **物理合理性复核**：cos 的 k=1 / k=7 共轭对称、方波只现奇次谐波、冲激频谱平坦、直流仅 k=0 有值——均符合理论。

## 五、应用与传播价值（对应「应用与传播价值」10 分）

- **真实场景落地**：第 4 章把算法放回播放器频谱、降噪耳机、设备（电机）体检；音高实验室把"频率"翻译成"音高"，并支持**上传浏览器可解码的真实音频做频谱分析**（受「落谱 luopu.net」启发，但完全自行离线实现，把"音频转音高"的第一步数学完整呈现；短音频会自动补零到 2048 点）。
- **易于传播**：零依赖、单文件夹、可双击运行，亦可直接打包分发或离线演示，适合作为智慧教育科普资源在课堂与社群传播。
