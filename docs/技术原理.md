# 技术原理说明

本文件补充说明作品涉及的数学原理，供评审与观众深入理解。

---

## 一、DFT：离散傅里叶变换

对长度为 N 的离散信号 x[n]，其 DFT 定义为：

```
X[k] = Σ(n=0..N-1)  x[n] · e^(−j·2π·k·n/N)      k = 0, 1, …, N−1
```

**直观解释**：把原信号与一个频率为 k 的复正弦逐点相乘再求和。
若结果幅值大，说明信号中确实含有该频率成分。

**计算代价**：每个 k 需要 N 次复数乘法，共 N 个 k，总计 **N²** 次。
N = 1024 时约 100 万次，N = 4096 时约 1600 万次。

---

## 二、旋转因子

定义：

```
W_N = e^(−j·2π/N)
W_N^k = e^(−j·2π·k/N)
```

几何意义：W_N 是复平面单位圆上、角度为 −2π/N 的一个点。
W_N^k 就是把它旋转 k 次。它只改变相位，不改变幅值。

**周期性**：W_N^(k+N) = W_N^k
**对称性**：W_N^(k+N/2) = −W_N^k

这两条性质是 FFT 能够"分治"的根本原因。

## 三、基-2 时域抽取 FFT

### 3.1 分治推导

把 x[n] 按下标奇偶分成两半：

```
E[k] = DFT_{N/2}( x[0], x[2], x[4], … )     偶数下标
O[k] = DFT_{N/2}( x[1], x[3], x[5], … )     奇数下标
```

利用旋转因子的周期性，可以证明：

```
X[k]        = E[k] + W_N^k · O[k]       k = 0 … N/2−1
X[k + N/2]  = E[k] − W_N^k · O[k]       k = 0 … N/2−1
```

这两个式子结构完全相同，只有中间符号不同——正是**蝶形运算**。

### 3.2 蝶形单元

```
        a ──────┬──────► A = a + W·b
                │
        b ──×W──┤
                │
                └──────► B = a − W·b
```

一次蝶形：1 次复数乘法 + 2 次复数加法，产出 2 个输出。

### 3.3 复杂度

每一级有 N/2 只蝴蝶，共 log₂N 级：

```
复数乘法次数 = (N/2) · log₂N
```

对比 DFT 的 N²：

| N | DFT (N²) | FFT ((N/2)·log₂N) | 加速比 |
|---|---|---|---|
| 8 | 64 | 12 | 5× |
| 64 | 4,096 | 192 | 21× |
| 1024 | 1,048,576 | 5,120 | 205× |
| 4096 | 16,777,216 | 24,576 | 683× |

### 3.4 按位反转

时域抽取 FFT 要求输入按"位反转顺序"重排。
以 N = 8（3 位）为例：

```
原下标  二进制   反转后   重排下标
  0     000     000        0
  1     001     100        4
  2     010     010        2
  3     011     110        6
  4     100     001        1
  5     101     101        5
  6     110     011        3
  7     111     111        7
```

作品中的实现已通过测试验证该序列为 `0,4,2,6,1,5,3,7`。

## 四、作品中的实现策略

### 4.1 保留各级快照

标准 FFT 只返回最终结果。本作品在每一级运算结束后复制一份数组状态：

```javascript
stages.push({ len, re: re.slice(), im: im.slice() });
```

这样第 3 章可以逐级回放，让观众看到中间结果如何一步步演化。

### 4.2 DFT 用于交叉验证

作品同时内置了按定义实现的朴素 DFT，仅用于测试比对，
确保 FFT 实现的正确性（详见创作说明第五章的验证数据）。

### 4.3 实数输入的共轭对称性

本作品的所有输入均为实数（虚部为 0）。对实数信号：

```
X[N−k] = conj( X[k] )       即 |X[N−k]| = |X[k]|
```

因此频谱图呈现左右对称的双峰——这是第 3 章可观察到的现象之一，
也是实际工程中"实数 FFT 只需算一半"的依据。

## 五、应用场景补充

| 领域 | 用 FFT 做什么 |
|---|---|
| 音频处理 | 分帧做频谱，用于降噪、均衡、音高识别 |
| 机械监测 | 振动信号频谱，对照转速倍频判断故障类型 |
| 无线通信 | OFDM 调制解调的核心运算 |
| 医学影像 | MRI 图像重建（k 空间到图像空间） |
| 雷达/声呐 | 脉冲压缩、目标速度测量 |
| 地震勘探 | 地层反射信号分析 |

共同点：**只要一个物理量能被采样成序列，FFT 就能告诉我们它由哪些频率构成。**
