# 《频谱之诗》使用说明

## 运行方式

**方式一（推荐）**：直接双击 `index.html`，用 Chrome 或 Edge 打开。

**方式二**：若浏览器限制了本地文件访问（麦克风 / 音频解码等能力需要），可在作品目录下启动一个简易服务：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

> 作品为纯静态实现，**无需安装任何依赖，无需联网**。
> 注意：麦克风与「上传音频」需要 `https` 或 `localhost` 环境；
> 直接双击打开时这两项会给出明确提示，其余内容（公式、动画、自测、合成乐音）完全可用。

## 各章交互操作指南

### 第 1 章
- **实验 1**：拖动三个"频率"和"振幅"滑块，观察左侧合成波形与右侧频谱柱的联动
- **实验 2**：拖动"试探频率"滑块，观察相关系数变化。数值接近 1 时说明频率匹配
- **谐波实验室**：拖动 1/3/5/7 次谐波滑块，或点「方波」预设，观察波形与频谱的对应

### 第 2 章
- 拖动"N"滑块（N = 2^1 至 2^10），观察两条曲线在对数坐标下的分离程度
- 下方两张卡片实时显示 DFT 与 FFT 的具体乘法次数与加速比
- 位反转演示：观察二进制下标如何重排

### 第 3 章（重点）
- **信号类型**：切换正弦 / 方波 / 冲激 / 直流
- **频率滑块**：正弦模式下调整周期数
- **下一级 →**：逐级展开蝶形运算，观察每一级的中间结果
- **一次跑完**：直接展示全部三级
- **重置**：回到初始状态
- 下方左右两图分别为时域波形与输出频谱，随参数实时刷新

**推荐操作序列：**
1. 保持默认正弦，点"一次跑完"，观察频谱双峰
2. 切到"方波"，点"一次跑完"，观察奇次谐波
3. 切到"冲激"，观察频谱变平坦
4. 切到"直流"，观察能量全部集中在 k=0

### 第 4 章
- **场景 1**：拖动"基频音高"滑块，观察所有谐波峰整体平移
- **场景 2**：拖动"转速"滑块改变转频；勾选"不平衡故障"，观察 1× 处出现尖峰
- **场景 3**：JPEG 高频取舍示意（静态图解）

### 第 5 章
- 第 1 题为拖拽题：把概念标签拖到对应定义上（触屏设备可点击标签再点击目标）
- 第 2-7 题为选择题：点击选项即时反馈
- 点击"提交全部并计分"查看总分；满分可解锁「满分学者」徽章
- 下方「探索成就」列出全部 **14 枚徽章**，随各章任务完成自动点亮

### 音高实验室（延伸实验）
- **弹与看**：点击琴键（或 Tab + 回车）弹奏 C4–C5，观察实时 FFT 频谱。
  基频与 2、3 次谐波会被高亮成蓝柱
- **听音辨频**：点「开始游戏」，系统播一个音，你在琴键上找出它。
  点任意琴键即提交答案（会同时奏响便于 A/B 对比），连续答对 3 题完成
- **上传一段音频**（本作品最接近真实数据的实验）：
  1. 点「选择音频文件…」，选一个本地音频（mp3 / wav / m4a / ogg 等）
  2. 浏览器解码后，程序自动取能量最大的 2048 个采样点，加 Hann 窗
  3. 用第 3 章那套**基-2 时域抽取 FFT** 计算，绘出时域波形与频谱
  4. 读出主频，并换算出最接近的音名与偏差（音分）

> 文件全程只在本机浏览器内处理，不会上传到任何服务器。

## 常见问题

**Q：打开后页面没有样式？**
A：请确认 `assets/` 文件夹与 HTML 文件在同一目录下，且未被单独移动。

**Q：第 3 章图形不显示？**
A：请使用 Chrome / Edge / Firefox 最新版。IE 浏览器不支持本作品使用的 SVG 与 Canvas 特性。

**Q：点琴键没声音 / 麦克风按钮无反应？**
A：音频能力需要 `https` 或 `localhost`。请用 `python -m http.server 8000` 启动本地服务后访问，
并确认浏览器已授权麦克风；上传音频功能同理。

**Q：上传音频提示"无法解码"？**
A：请改用浏览器能解码的格式（推荐 mp3 或 wav）。部分冷门封装格式（如某些 m4a）可能不被支持。

**Q：可以离线使用吗？**
A：完全可以。作品不依赖任何网络资源，也不上传任何数据。
